💡 为什么只有 Claude 显示 Cache Write（缓存写入），其他模型都是 0？
这是大模型厂商底层的计费返回机制差异：
• Anthropic (Claude) 采用显式缓存写入：新建前缀缓存时 API 会单独返回并计费 cache_creation_input_tokens（即 Cache Write），因此普通 Input 极少而 Cache Write 很高。
• OpenAI (Codex)、Google (Gemini/Antigravity)、DeepSeek、Tencent (WorkBuddy) 采用隐式自动缓存：首次输入建缓存的 Token 直接算在普通 Input 列中，不单独返回 Cache Write 字段；后续命中缓存则计入 Cache Read。
• 若要横向公平对比“非缓存读取的新增上下文”，建议在顶部将口径切换为 「净新增 (不含缓存读)」（即 Input + Cache Write + Output）。
